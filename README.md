# DT224G - Laboration 5
## Studentkortsgenerator

Denna uppgift gick ut på att skapa funktionaliteten till en studentkortsgenerator med hjälp av JavaScript.

## Hur sidan funkar
1. Användaren fyller i sina uppgifter i formuläret.
2. Formuläret valideras och eventuella felmeddelanden skrivs ut.
3. Om formuläret är korrekt ifyllt visas det färdiga studentkortet.
4. Alla studentkort sparas i en historik som lagras i localStorage.
